# PhonesThatPay

A proposed participant-and-business marketplace for verified, paid mobile-device work, developed by Highest Degree Priorities (HDP).

This repository hosts the public informational site at https://phonesthatpay.com. The initial version is a **pilot invitation**, not an active task market or promise of earnings.

The static site is published from `main` at the repository root through GitHub Pages when enabled by the repository owner. The `CNAME` file sets the planned custom domain.

## Principles

- Free to express interest; no device purchase is required to qualify for consideration.
- Compensation depends on paid assignments, verified completion, and applicable agreements; no income is guaranteed.
- Use participant-owned devices only with explicit permission and bounded, auditable tasks.
- Human approval, privacy, safety, and fair payment procedures precede expansion.
- HDP's cloud agents orchestrate verified work; phones contribute approved real-device capability.

## Publishing

GitHub Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save. Set/verify custom domain `phonesthatpay.com` and Enforce HTTPS after issuance. Check DNS, domain verification and browser results before calling the site live.
